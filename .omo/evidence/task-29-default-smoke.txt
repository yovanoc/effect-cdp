Task 29 — Default smoke script implementation

File: scripts/smoke.ts (140 lines)

Flow (default, no flags):
1. Parse argv → { test: "default", host: "http://127.0.0.1:9222" }
2. HttpDiscovery.version() → confirms browser endpoint reachable
3. HttpDiscovery.list() → find first target where type === "page"
4. Extract pageTarget.webSocketDebuggerUrl (fail with MissingWebSocketUrlError if absent)
5. Build CdpConfig { webSocketDebuggerUrl, eventBufferSize: 64 }
6. Provide Cdp.layerBun(config) (scoped)
7. Target.attach(cdp, pageTarget.id) → SessionId
8. Runtime.evaluate(cdp, sessionId, "1+1", Schema.Number)
   → assert === 2 → Effect.log("OK 1+1=2")
9. Page.goto(cdp, sessionId, "data:text/html,<...><button id=\"btn\" ...>")
10. DOM.querySelector(cdp, sessionId, "#btn") → nodeId
11. DOM.click(cdp, sessionId, nodeId)
12. Runtime.evaluate(cdp, sessionId, "document.title", Schema.String)
    → assert === "clicked" → Effect.log("OK click registered")
13. Exit 0 via BunRuntime.runMain

On failure: Effect.catch → Effect.logError(`smoke failed: ...`) → Effect.die → exit 1

Expected stdout (dry-run shape, when run against real Chromium with --remote-debugging-port=9222):
  timestamp=... level=INFO fiber=#... message="OK 1+1=2"
  timestamp=... level=INFO fiber=#... message="OK click registered"
