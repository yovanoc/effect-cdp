# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version packages and publish them to the npm registry
with a properly formatted changelog.

## What is a changeset?

A changeset is a piece of information about changes made to a package or a group of packages. It consists of:

- A human-readable summary of the changes
- Information about which packages are affected
- Whether the change is a major, minor, or patch release

## How do I create a changeset?

Run:

```bash
bunx changeset
```

This will open an interactive CLI to guide you through creating a changeset.

## How do releases work?

When changesets are present on the `main` branch, a GitHub Action will automatically create a "Version Packages" PR. When that PR is merged, the packages will be published to npm with provenance attestation via OIDC.

## OIDC Publishing

This repository uses **OIDC-based publishing** (no manual npm tokens). To enable:

1. Go to https://www.npmjs.com/package/effect-cdp/settings
2. Navigate to "Automation" → "Grant Access"
3. Add your GitHub repository as a trusted publisher:
   - **Provider**: GitHub Actions
   - **Repository**: `yovanoc/effect-cdp`
   - **Workflow**: `.github/workflows/release.yml`
   - **Branch**: `main` (optional, for extra security)
